Database maintenance

The tools of the eq-diagr programs DataMaintenance and AddShowReferences, running in the browser: statistics and checks of the databases, the data for a single component, conversion between binary and text databases, merging all databases into one, adding or editing reactions and components in a text database, and adding or editing literature references. The files stay in this browser.

    Program messages
    
    
    
    
    
      
    
        Statistics and checks
        
    Reads all databases and lists the reactants and their use, and the errors and warnings: reactants missing from the element files, reactions that are not charge balanced, duplicate reactions, and citations without a reference (if a references file is loaded). This is the file that DataMaintenance writes.

        Convert a binary database to text
        
    Writes the text database (.txt) and its element file (.elt), which can be edited here or in a text editor. The text format keeps fewer digits of the enthalpy data, so log K away from 25 °C can differ in the third decimal.
    
        
    
      
    

      
    
        Merge all databases into a single binary database
        
    All the databases above, in their order, are read and written as one binary database (.db with .elb). A reaction found again replaces the earlier one, and a name starting with "@" removes the earlier reactions with that name.
    
        
    
        
    
      
    

      
    
        Add data or edit a text database
        
    
        
    Reactions and components are added to a text database (a .txt file and its element file, .elt). The reactants offered are those of all the databases above and of this file. Choose "New text database…" to start a file of your own, for example with your own data, and use it together with the other databases.
