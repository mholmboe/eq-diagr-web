EC: Equilibrium Calculations

EC is a modified version of the Haltafall computer program. EC takes a series of chemical compositions and calculates the concentrations and activity coefficients of all species at equilibrium.

This is a console program, useful for batch (script) files,

  • You must be able to edit input data files with a text editor in order to use this program.
  • You must be able to create batch (script) files with a text editor in order to use this program.
Two output text files are created by the program: a verbose output file (with extension "out") and a table output file (with extension "csv") where the calculation results are reported column-wise with data separated by semicolons (";"). The table-output file may be imported into Excel or any other plotting program.
