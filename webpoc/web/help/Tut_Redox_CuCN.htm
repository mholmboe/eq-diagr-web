Reduction of Cu(II) to Cu(I) by cyanide: step by step

  1. In the Chemical system tab, click Cu (copper) in the periodic table and then Cu 2+. Click e− (the electron, in the top row of the periodic table). For cyanide, click C or N and then CN-. The selected components are H+, Cu2+, e− and CN−.
  2. Click Search reactions and then Create a diagram.
  3. In the diagram tab, choose the type Fractions, CN- as the X-axis component, and Cu 2+ under Fractions of component.
  4. In the Concentrations section:
    • H+: type total conc., value 1e-4;
    • e-: type total conc., value 0;
    • Cu 2+: type total conc., value 0.01 ([Cu]T = 10 mM);
    • CN-: type total conc. varied, from 0 to 0.03.
  5. Click Plot the diagram.
