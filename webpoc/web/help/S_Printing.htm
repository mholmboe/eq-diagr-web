Exporting and printing diagrams, and figures for reports

The buttons above the diagram, and the same items in the File menu, download the diagram or its data to your computer:

SVGa vector image, as drawn on the screen. It keeps its quality at any size, and can be inserted in documents (Word, LibreOffice and others) and edited in drawing programs such as Inkscape.
PNGa bitmap image for slides and web pages, 1600 pixels on the longest side unless you choose another size (800 to 4800 pixels) under PNG image in the diagram style.
PDFthe diagram as on the screen, with the fonts and colours of the diagram style. The labels use the standard PDF fonts (Helvetica, Times or Courier). These fonts are not embedded in the file: every PDF viewer has them (or a font with the same widths), so the file is small and shows the same layout everywhere, but a viewer may draw them with a similar font of its own.
EPS (advanced)encapsulated PostScript, made by PlotPS, the converter of the desktop programs: always with the plotter lettering of the plot file, whatever the diagram style, in colour or in black and white. See PostScript.
.plt (advanced)the plot file, which can be edited with a text editor (see making it pretty) and displayed again here (File > Open data or plot file…) or with the desktop Spana.
.csvSED diagrams: the values of the curves as a table, for a spreadsheet or another plotting program. See table output; the file name extension and the separator can be changed in the Options (advanced mode).
.datthe data file, with the current settings. It can be opened again here, or in the desktop programs.

The diagram style (Style… above the diagram) sets the font, text size, colours and line width of the SVG, PNG and PDF files, as on the screen. EPS files are made by PlotPS with the lines of the plot file, in colour, or in black and white when the style is black and white.

The page of PDF and PostScript files

Under PDF and PostScript page in the diagram style you choose, as in the conversion window of the desktop Spana:

Pagethe diagram alone (the page is as large as the diagram), or an A4 or Letter page.
Orientation, Left, Bottomfor an A4 or Letter page: portrait or landscape, and the distance in cm from the left and bottom edges of the page to the diagram.
Size50 to 200 % of the size of the diagram.
header linethe name of the diagram and the date, at the top of the page.
PostScript file (advanced)EPS, the diagram alone for insertion in a document, or PS, a page for a printer. The button above the diagram is named after the choice.

Copying the diagram

Copy above the diagram (or File > Copy the diagram as an image) puts the diagram on the clipboard as a PNG image, as drawn on the screen and with the size chosen for PNG files. Paste it in a document, a slide or a message. A browser that cannot copy images says so; use the PNG file instead.

Printing

File > Print the diagram… (Ctrl+P, or ⌘+P on a Mac, while a diagram tab is shown) opens the print dialog of the browser with the diagram alone, drawn with the diagram style and scaled to the width of the page. Choose landscape in the dialog for a larger diagram. You can also export the diagram as PDF and print that file.

Making it pretty

  • Choose the font, text size, colours, line width, tick marks, grid and frame with Style…, and the step between the numbers of the axes in the Options (advanced mode); see the diagram style.
  • Change the text height, the title, the concentration units and notation in the Options (advanced mode), and make the diagram again.
  • Edit an exported SVG in a drawing program, for example to move labels, change colours or fonts.
  • Edit the plot file (.plt, advanced mode) with a text editor, see the plot file format.
