SPANA

Working with the app

The program runs in one browser window with a menu bar at the top, a list of files on the left, tabs in the middle and a status line at the bottom.

Tabs

  • Chemical system: the database search (the desktop DATABASE), always open. See searching the database.
  • One tab for each data file that is open, named after the file: the diagram settings and the diagram (the desktop SPANA). See making a diagram. A dot before the name means that the tab has changes not yet saved in this browser.
  • Database tools (advanced mode): statistics, conversion, merging and editing of databases and references (the desktop DataMaintenance and AddShowReferences).
  • Help: these pages. The field above the contents searches all of them: type one or several words to list the pages that have all of them, those with the words in the title first; the Escape key brings the contents back.

Close a tab with its ×, or with File > Close tab.

The file list

Data files lists the data files saved in this browser; click one to open it, and click its × to remove it. Databases shows the database in use. The button ☰ at the top left hides or shows the list. See files in the browser.

Two kinds of files

  • Data files (.dat) hold a chemical system and the settings of a diagram. They are made by the database search, and they are the files the desktop programs use too. See the data file format.
  • Plot files (.plt) hold a diagram, as SED and PREDOM write it. In advanced mode you can download the plot file of a diagram, for example to change it by hand or to open it in the desktop Spana. See the plot file format.

Opening a data file

  • From a search: Create a diagram in the Chemical system tab.
  • From constants of your own: File > New chemical system (manual input)…, a form for pKa values, stability constants and solubility products (see manual input of constants).
  • From this browser: click the file under Data files.
  • From your computer: File > Open data or plot file… (or Open… above the file list), for example a .dat file made with the desktop programs or written by hand in a text editor. A data file saved with the ending .txt is opened as well. Older files and files saved from a Windows text editor, where a name such as FeSO4·7H2O(cr) is stored in the Windows encoding and not in UTF-8, are read with their names intact. If a file is not a data file, the program says what it could not read and opens no tab.
  • A plot file (.plt) opens the same way, from the menu or by dragging. It is shown in a tab with the drawing alone, without settings: it can be exported, copied and printed, and the diagram style applies to it, but it cannot be calculated again without its data file.
  • By dragging: drop one or several .dat files from your computer anywhere on the window. Database files dropped on the window are loaded as with Database > Load database files….
  • From a link made with File > Copy a link to this diagram, see sharing a diagram with a link.
  • An example: File > Open an example…, see example files.

Colours

View > Colours sets the colours of the program:

  • As the computer follows the light or dark appearance chosen in the operating system or the browser;
  • Light and Dark keep one of the two;
  • Original has the greys, the dark blue titles and the square buttons of the desktop programs, with the periodic table on the yellow panel of DATABASE.

The diagram itself stays black on white in all of them, as on paper; its colours are set with the diagram style. The help pages also stay light.

On a phone or tablet

The app runs in the browser of a phone. On a narrow screen the file list becomes a drawer, opened with ☰, and the diagram comes below the settings, or stays above them in live mode.

  • In the Chemical system tab, the elements that the database has are shown as large buttons, with H and e− first, in place of the periodic table, whose cells would be too small for a finger.
  • Where the help says “point at” a text to see an explanation (the reaction of a species, the mark of a pKa, a reference), tap the text: the explanation is shown in a bubble until the next tap.
  • Full screen, above a diagram, shows the diagram alone, without the menus and tabs. Turn the phone for a wider diagram; the browser's own zoom (two fingers) works as usual. Touch the diagram to read values off it.
  • Sliders, saving in the browser, opening files and the exports work as on a computer. Advanced mode is available (View > Advanced mode) but is laid out for a larger screen.

The command-line programs can also be run on their own, see batch mode.
