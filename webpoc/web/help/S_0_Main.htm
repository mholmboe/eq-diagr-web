Chemical Equilibrium Diagrams

SPANA: chemical equilibrium diagrams

Each data file opens in a diagram tab, the web version of the desktop program SPANA. There you change the chemical system if needed, choose the type of diagram, the axes and the concentrations, and make the diagram. The calculations are made by SED and PREDOM, the same programs as on the desktop (compiled to run in the browser), and the diagram is drawn next to the settings.

Data files come from a search in the Chemical system tab, from the examples, or from your computer (File > Open data file…). Several diagram tabs can be open at the same time.
