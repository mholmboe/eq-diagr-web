SED & PREDOM

Output of calculated values

Table output from SED

Output files can be generated by SED with the curves in the diagrams. These files are plain text files that will get the same name as the plot-file, but with an extension selected by the user.

Table output can be obtained either by:

  • running from the command line or from a batch file
  • in the web version: SED always writes the table, and the button .csv above the diagram downloads it. In advanced mode the file name extension, the column separator and the comment characters are chosen under Table of results in the diagram's Options.
You can use these table files to insert the calculation results into a spread-sheet (such as Excel), or you can plot the data with some other plotting program. The output table file created while making a logarithmic diagram contains also infromation on activity coefficients for all species.

Output from Predom

Predom generates a list of points defining the boundaries between areas of predominance. This list is probably not useful to most users. Nevertheless, the list may be obtained either:

  • using the “-dbg -keep” command line parameters
  • in the web version: in advanced mode, tick “write messages in SED and Predom” in the diagram's Options; the list is then under Program messages below the diagram.
With the desktop programs the list is found, after the calculations, in the “Messages” tab of Predom, where the menu “debug / save messages to file” saves it to a text file. In both versions the information may be copied and pasted.

Table output from EC

EC generates both an output file with details of the calculation results, and a table file. You can use the table file to insert the values into a spread-sheet (such as Excel), or you can plot the data with some other plotting program. The table file contains both concentrations and activity coefficients for all species.
