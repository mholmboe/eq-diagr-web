Files in the browser

The program has no files of its own on your computer. The data files you make are kept in the storage of this browser, for this web address, and the calculations run in the browser too: nothing of them is sent to a server. A hosted copy of the app may count its visits (see Help > About Eq-Diagr there); the count has the address of the page and the width of the screen, never your files.

Data files

  • A data file is saved in the browser when you make it from a search (Create a diagram), each time you make its diagram, and with File > Save data file in this browser, which also lets you give it another name. In live mode it is saved when the settings have been left unchanged for two seconds. These saves leave out a changed log K, which is kept only by File > Save data file in this browser.
  • The saved files are listed under Data files on the left; click one to open it, and click its × to remove it from the browser (this cannot be undone).
  • A tab with changes not yet saved has a dot before its name. Closing it asks whether to save the changes, and the browser warns you if you close or reload the page while a tab has unsaved changes.
  • A file opened from your computer, or an example, is saved in the browser under its own name when you make its diagram, unless a saved file already has that name; then use File > Save data file in this browser to choose a name.

Keeping your files

Browser storage belongs to one browser on one computer. Your files are not there in another browser, on another computer, or in a private window, and they are deleted if the browser's site data are cleared. To keep a file, or to move it, download it with .dat above the diagram (or File > Download data file), and open it later with File > Open data or plot file….

Sharing a diagram with a link

File > Copy a link to this diagram puts a web address on the clipboard that holds the data file itself, with its diagram settings, in the part after the #. Whoever opens the link gets the file in a new diagram tab, and the diagram is made at once. This is a quick way to hand a chemical system to a class, or to send a diagram to a colleague.

  • The data are in the link and nowhere else: browsers do not send the part after the # to the web server, and nothing is stored on a server. The link keeps working as long as the program is at the same web address.
  • The link is a copy. Changes made by the receiver stay in the receiver's browser, and your later changes are not in a link you copied earlier.
  • The link is as long as the (compressed) data file: a few hundred characters for a small system, several thousand for a large one. Some e-mail and chat programs cut very long links; send the downloaded .dat file instead in that case.
  • The diagram style is not part of the link; the receiver sees the diagram in their own style.

Databases

The databases that come with the program are loaded from the web site when they are chosen; only the choice is remembered. Database files of your own, loaded with Database > Load database files…, are kept in the browser if remember your own database files in this browser is ticked (in the Chemical system tab); untick it to forget them. See databases.

Settings

The browser also remembers normal or advanced mode, the colours of the program, the diagram style, live mode, the options of the database search and whether the file list is shown. The settings of a diagram are kept in its data file.
