EC (HaltaFall) running in the browser

The eq-diagr calculation code (LibChemDiagr and EC), compiled from Java to JavaScript with TeaVM and run in a Web Worker, run on the three EC regression cases and compared with the reference CSV tables committed in eq-diagr/EC/tests (relative tolerance 1e-6, absolute 1e-12, as in test-cli.sh). The numerical code is unchanged; the build only replaces the AWT message box, the program exit and the %e/%f/%g/%n formatting that TeaVM lacks.
