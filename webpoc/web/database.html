Database search running in the browser

The eq-diagr DataBase search (DBSearch and the database library), compiled from Java to JavaScript with TeaVM and run in a Web Worker. Choose the components, search the database for all complexes and solids they form, and save the chemical system as a .dat file, as the desktop DataBase program does. The database files are read by this page only; nothing is sent to a server.

Loading the database…

Three databases come with the program: the database of the KTH course KD1280 (the default; log K at 25 °C only), the database of the eq-diagr release (with its literature references and data for other temperatures), and a small sample. To use your own, load a .db file together with its .elb file (or a text .txt or .skv database with its .elt or .elm file), and a references file (References.txt) to see the literature references. A database in the format of CHESS (.tdb) is converted to a text database when it is loaded.

Database tools
        
Convert a loaded binary database (.db with .elb) to the text format (.txt with .elt), as DataMaintenance does. The text files can be edited, for example to add your own reactions, and loaded here again. Note that the text format keeps fewer digits of the enthalpy data, so log K away from 25 °C can differ in the third decimal.
