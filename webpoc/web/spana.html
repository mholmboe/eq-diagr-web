Chemical equilibrium diagrams in the browser

Spana's diagram setup on top of the eq-diagr programs (SED, Predom, PlotPDF, PlotPS, ModChemSyst, ModReaction), compiled from Java to JavaScript with TeaVM and run in a Web Worker. Open a data file, or make one with the database search; choose the diagram, the concentrations and the options; and make the diagram. Files stay in this browser.
