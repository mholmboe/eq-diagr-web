Predom (Predominance Area Diagrams) running in the browser

The eq-diagr Predom calculation (HaltaFall on a grid of points) and plot generation, compiled from Java to JavaScript with TeaVM and run in a Web Worker. The diagram is the .plt file Predom writes, drawn as SVG. Input is the usual Predom .dat file; options are Predom's command-line options (-n= steps per axis, -i= ionic strength, -t= temperature, -m= activity model, -aqu aqueous species only, -ph neutral-pH line, -tol=, -units=, -sci, -eng, -rev).
