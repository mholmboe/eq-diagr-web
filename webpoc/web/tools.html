Chemical equilibrium diagrams in the browser

The eq-diagr programs by Ignasi Puigdomènech (DataBase, Spana, SED, Predom and their tools), compiled from Java to JavaScript and run in your browser. The calculations are the same as in the desktop programs; your files and databases stay on this computer.

DatabaseMaintenanceDiagramSEDPredomHelpEC tests

Open the app → One window with menus, a file list and tabs for the chemical system, the diagrams, the database tools and the help. Normal mode shows what most diagrams need; advanced mode shows all the options of the programs.

The pages below are the same tools, one page each.

1. Chemical system

Choose the components in a periodic table, search the thermodynamic database for all complexes and solids, and leave out species you do not want.

Database search →

2. Diagram

Choose the diagram type, the axes and the concentrations, edit log K values or the components, and make the diagram. Download it as SVG, PNG, PDF or EPS.

Diagram setup →
  • SED and Predom: run the diagram programs directly on a data file, with their command-line options.
  • Manual input of constants: pKa values, stepwise or cumulative stability constants and solubility products written as a data file or a text database.
  • Database maintenance: statistics and checks of the databases, the data for a single component, conversion between binary and text databases, merging databases, adding your own reactions and components, and editing the literature references (the desktop DataMaintenance and AddShowReferences).
  • Help: the help pages of the desktop programs, with tutorials and the format of the data files.
  • EC tests: the equilibrium calculator on its regression cases, compared with the reference results.
