SED (Simple Equilibrium Diagrams) running in the browser

The eq-diagr SED calculation (HaltaFall) and plot generation, compiled from Java to JavaScript with TeaVM and run in a Web Worker. The diagram is the .plt file SED writes, drawn as SVG. Input is the usual SED .dat file; options are SED's command-line options (-n= steps, -i= ionic strength, -t= temperature, -m= activity model, -tol=, -thr=, -units=, -sci, -eng, -rev).
