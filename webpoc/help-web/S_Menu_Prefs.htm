Normal and advanced mode

Normal mode shows the options needed for most diagrams, and is meant for teaching. Advanced mode shows all the options of the programs, as the "advanced" program level of the desktop programs does. Switch with the buttons Normal and Advanced at the top right of the window, or with View > Advanced mode. The browser remembers the choice.

In normal mode the advanced options are not used: the diagrams are made with the default values, and the database search includes all solids and all redox equilibria. Your settings in advanced mode are kept, and used again when you switch back.

Desktop preferences that the web version does not need

The paths to SED and PREDOM, the text editor, file associations and keeping calculation windows open belong to the desktop installation. The fonts, colours and lines of the desktop "Diagram windows" preferences are set with the diagram style, in both modes; the size of the diagram follows the window. The colours of the program itself (light, dark, or as the desktop programs) are chosen with View > Colours.
