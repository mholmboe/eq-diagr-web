Constants entered by hand

Equilibrium constants from a textbook, a table or an article can be entered as they are given there (pKa values, stepwise or cumulative stability constants, solubility products), without a database. The program writes them as a data file and opens it for a diagram.

  1. Choose File > New chemical system by hand… (or the link under the periodic table of the Chemical system tab). The By hand tab opens.
  2. Enter what you have, with one entry for each acid, each metal with a ligand, and each solid (see below). Fill in an example shows the three kinds of entries.
  3. The table on the right shows the chemical system as it is written to the data file: every species formed from the components, with its accumulated log K, beside the step you entered.
  4. Give the data file a name and click Create a diagram. The file is saved in this browser and opened in a diagram tab, where the diagram type, the axes and the concentrations are chosen as for any other chemical system.

What is entered stays in the By hand tab, also after the browser is closed, so that a value can be corrected and the diagram made again. Start again empties the tab.

The three kinds of entries

EntryWhat is givenWhat is written
Acid or base The base, which is the form without the protons of the acid (PO4 3- for phosphoric acid, NH3 for the ammonium ion), and the pKa values of its acids, one for each proton and in any order. With pKb values the values are those of the bases, and pKa = pKw − pKb. The acid with n protons, with log K equal to the sum of the n largest pKa values. For 2.15, 7.20 and 12.35: HPO4 2- 12.35, H2PO4- 19.55 and H3PO4 21.70.
Metal ion with a ligand The metal ion (Cu 2+), the ligand (NH3) and one constant for each complex, in the order of one, two, three ligands: the stepwise constants log K1, log K2, … or the cumulative constants log β1, log β2, … The complex with n ligands, with log βn, which for stepwise constants is the sum of the first n of them.
Solid or other reaction The product, the reactants it is formed from with their coefficients (an empty coefficient is 1), and log K of the formation. For a solid, log Ksp can be given: the reaction is then read backwards, as the solid dissolving into the reactants. The product, with log K of its formation (−log Ksp for a solubility product).

Water. With the box with H+ and OH− ticked, H+ is a component and OH− is added with the pKw given (14.00 at 25 °C). A data file has no component for OH−, but it may be written as a ligand or a reactant: each OH− is converted to H2O − H+, and pKw is subtracted from log K. Copper hydroxide with log Ksp = −19.66, entered as Cu(OH)2(s) formed from Cu 2+ and 2 OH-, is written as Cu2+ + 2 H2O ⇌ Cu(OH)2(s) + 2 H+ with log K = 19.66 − 28.00 = −8.34. H2O itself is left out of the reactions.

Names. Names are written as in the databases (see names and numbers): the charge at the end, as in PO4 3-, Cu 2+ or CH3COO-; a solid ends with (s), (c), (cr) or (am), and a gas with (g). The program makes the names of the acids and the complexes (H2PO4-, Cu(NH3)4 2+); such a name can be changed in the table, and an emptied field gives the name of the program again. If the charges of a reaction do not add up, a warning is shown, which most often points to a charge missing in a name.

Components. Every reactant becomes a component of the data file, and a component cannot also be a product. If HCO3- is the base of one entry and the acid made in another, the program says so: write both entries with the same base, CO3 2-.

The program takes the constants as valid for zero ionic strength and for one temperature (25 °C, or the temperature given in advanced mode). Constants measured in an ionic medium, or taken from tables for different conditions, are used as they are, and the diagram is then only as consistent as the constants. See also how to get equilibrium constants.

The same constants as a database

In advanced mode, Use as a database… writes the same reactions as a text database (a logK file .txt with its element file .elt) and hands the two files to the Chemical system tab, which asks whether they are added to the databases in use or used instead of them. A search then finds your reactions together with those of the other databases, and a reaction of yours replaces one of the same name in a database before it. A text database holds constants at 25 °C, so this is not offered for another temperature. Single reactions can also be added to a text database in the Database tools tab (see adding data).
