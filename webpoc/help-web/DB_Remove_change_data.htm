DATABASE / Databases

Removing or changing data

The databases are read in order, and when two reactions have the same product, only the one read last is kept. Data are therefore removed or changed with a database of your own that is read after the others. The order is shown in the Database tools tab (advanced mode), where the arrows ↑ and ↓ change it.

For one diagram

To change a log K or leave out a species in one chemical system only, there is no need to change the database: do it in the diagram tab, see changing the chemical system, or untick the species in the search result (searching the database).

For all searches

Make a text database of your own as described in adding data, and:

  • change a log K by adding the reaction again, with the same product name and the new value;
  • remove a reaction by adding a reaction product with the same name preceded by "@". For example, the product "@FeOH 2+" removes "FeOH 2+"; its log K is not used. See remove a reaction;
  • remove a component from the list of an element by adding a component with the same name preceded by "@". For example, "@Fe 2+" linked to Fe removes Fe(II) from the components of iron.

For a class

Database files of your own are loaded with Database > Load database files… and kept in the browser of each student (see files in the browser). To give the same changes to a whole class, hand out the .txt and .elt files together with the database they change, so that they are loaded together. Alternatively, the files can be added to the databases that come with the program by those who run the web site.
