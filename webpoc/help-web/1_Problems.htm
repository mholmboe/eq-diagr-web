Chemical Equilibrium Diagrams / Running in the browser

Problems?

There are two kinds of problems: the program does not work, or it works but the results seem wrong.

The results seem wrong

  • Parts of the diagram are missing: the calculations failed. The status line says how many points failed, and Program messages below the diagram says which.
  • In a predominance area diagram parts of some lines are missing: try more Steps (advanced mode).
  • The diagram seems wrong. Check the chemical system (are the solids that should not form switched off? see solids) and the concentrations.
  • The equilibrium constants from the database are wrong: change the data, or change log K in the diagram tab (changing the chemical system).

The program does not work

  • Nothing happens, or the page stays empty: use a recent browser (Firefox, Chrome, Edge or Safari) and reload the page. The program needs JavaScript and Web Workers.
  • A search or a diagram stops with a message: open Search messages (Chemical system tab) or Program messages (diagram tab). They show the output of the programs, as the message windows of the desktop programs do.
  • For more detail, switch to advanced mode and tick write messages in SED and Predom, or raise Debugging in HaltaFall, in the diagram's Options.
  • A calculation takes too long: click Stop (or Run > Stop the calculation), and try fewer steps.
  • Your data files are gone: they are kept in one browser on one computer, see files in the browser.

The programs make the same calculations as the desktop programs. If you find an error in the results, check whether the desktop programs give it too: errors in the calculations are for the author of the programs, errors of the web version for those who run this web site.
