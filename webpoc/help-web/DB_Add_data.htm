Adding data

New components and new reactions are added to a text database of your own (a logK file .txt with its element file .elt), which is then used together with the other databases. This is done in advanced mode:

  1. Choose Database > Add data or edit a text database. The Database tools tab opens, with the list of databases in use at the top.
  2. Under Add data or edit a text database, choose New text database… (or a text database already in the list) and click Open. A new database needs a name, for example New-Data.txt.
  3. To add a reaction, give the reaction product, the reactants with their stoichiometric coefficients, and log K° at 25 °C (with ΔH° and ΔCp° if you have them, for other temperatures), a reference and a comment, and click Save reaction. The reactants offered are the components of all the databases in use and of this file. A reaction that is not charge balanced is reported.
  4. To add a component (a new ligand, for example), give its name and description, choose the elements it is listed under in the periodic table, and click Save component.
  5. Click Download .txt and .elt to keep the two files on your computer.

When the first reaction or component is saved, the new file is added last to the list of databases, so that its reactions replace reactions of the same name in the databases before it (see removing or changing data). The Chemical system tab uses the same list.

Only text databases (.txt with .elt) can be edited here. A binary database (.db) can first be converted with Convert a binary database to text in the same tab.
