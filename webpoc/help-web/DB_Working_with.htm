Searching the database: the Chemical system tab

Choosing the components

When the program starts, H+ is already selected. Click an element in the periodic table to list its components (metal ions or ligands) under Available for …, and click a component to select it. An element with a single component, for example Na or Cl, is selected directly by the click on the element. The selected components are listed at the top of the right-hand side; click one there to remove it. The elements with a selected component are marked in the periodic table, and elements without data in the database are greyed out.

  • Organic ligands are found under carbon, C (in the eq-diagr database).
  • Select electrons, with e− in the top row of the periodic table, if you want diagrams with the redox potential (Eh or pe) on an axis, or if your system has an element with several redox states, for example Fe(II) and Fe(III). See redox reactions.
  • In advanced mode, a database's components that are not linked to a chemical element (for example some ions of the Medusa-Hydra database) are listed under other, under e−. Water is added with the option include H2O as a component (see below).
  • If you select two components of the same element, for example Fe 2+ and Fe 3+, the search warns you that they may be related by redox reactions, and asks whether to continue.

File > New chemical system clears the selection (H+ stays) and the search result.

Searching

Click Search reactions. The reactions found are listed with their log K at the chosen temperature and their reference. Point at a species name to see its reaction, and at a reference key to see the full reference (the eq-diagr database has the references; the KTH database has only the keys).

Click a species name to see the details of its reaction, as show Details does in the desktop DataBase: the reaction, log K° at 25 °C and at the temperature of the search, ΔH° and ΔCp° (or a note that log K comes from a function or a table of values), the temperature and pressure up to which the data are valid, the references in full, and the comment of the database. A species of the KTH database has no data for other temperatures than 25 °C.

To leave a species out of the data file, untick it. The search is made again without it, and the species is shown unticked at the end of the list, so that you can take it back. This is how you exclude a solid that should not form in your experiment.

Options

  • Temperature, and in advanced mode the pressure: see temperature. The KTH database has log K values at 25 °C only.
  • Solids (advanced mode): include all solids, or exclude those whose names end with "(cr)" or "(c)", see solids. In normal mode all solids are included.
  • Redox equilibria (advanced mode): when e− is a component, the redox reactions of nitrogen, sulfur and phosphorus can be left out, for example to keep N2(g) or NH4+ from forming in a nitrate solution. In normal mode they are all included.
  • Include H2O as a component (advanced mode): for databases that have water as a component, see water. Water is normally not needed as a component, because its activity is taken as one.

Making the data file

Create a diagram saves the data file in this browser and opens it in a new diagram tab. The file is named after the components, for example H+_Fe2+.dat; if a file with that name already exists, you are asked for another name (keeping the name replaces the old file). File > Download data file (.dat) saves the data file on your computer instead (in advanced mode there is also a button Download .dat). See making a diagram.

The messages of the search (the files read, the reactions found and any warnings) are under Search messages.

Using the keyboard

All buttons and fields can be reached with Tab and Shift+Tab, and Space or Enter clicks the button in focus. In the menu bar, the arrow keys move between and within the menus and Esc closes them.
