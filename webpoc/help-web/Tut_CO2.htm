Diagrams at constant gas pressure: log PCO2 = constant

The databases list the carbonate reactions with CO32− as the component, so a diagram made directly from the search has a fixed total concentration of carbonate. For a solution in contact with air, or with a given CO2 pressure, CO2(g) must be a component instead. This is done by exchanging a component for one of its reaction products.

  1. In the Chemical system tab, click C (carbon) in the periodic table and then CO3 2-. The selected components are H+ and CO32−.
  2. Click Search reactions and then Create a diagram. The diagram tab opens.
  3. Open the Chemical system section at the top of the diagram tab. In the row of CO3 2-, choose CO2(g) in the list exchange for…. The components are now H+ and CO2(g), and all reactions are rewritten with the new component.
  4. In the Concentrations section, CO2(g) now has the type log P, with the value −3.5 (air). Change it if you want another pressure.
  5. Click Plot the diagram.

Compare this diagram with the one made when CO32− is the component, with a total concentration of, for example, 10 mM.

The changed chemical system is saved in this browser under the name of the original file when you make the diagram. To keep both versions, first use File > Save data file in this browser and give the new system its own name, for example CO2(g).dat.
