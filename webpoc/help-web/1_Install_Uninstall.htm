Chemical Equilibrium Diagrams

Running in the browser

This version of Chemical Equilibrium Diagrams runs in a web browser and needs no installation. The calculation programs of the desktop version (DataBase's search, SED, PREDOM, HaltaFall, PlotPDF, PlotPS and the programs that change data files) are compiled from their Java source to JavaScript, and they run in the browser, so the results are those of the desktop programs. A recent version of Firefox, Chrome, Edge or Safari is needed.

Your data files are kept in the browser, see files in the browser. To remove everything the program has stored, clear the site data of this web address in the browser's settings.

The desktop version

The desktop programs (for Windows, macOS and Linux, with Java) are installed from the eq-diagr releases at github.com/ignasi-p/eq-diagr. They keep their settings in "ini" files, which the web version does not use; data files (.dat) and plot files (.plt) can be exchanged between the two versions.
