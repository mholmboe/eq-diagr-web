Example files

The program comes with the example data files of the desktop programs. Open one with File > Open an example… or Help > Example diagrams…, look at the chemical system and the settings in the diagram tab, and click Plot the diagram. The diagram you get is the one shown here (the web version makes the same plot files as the desktop SED and Predom). See also the tutorials.

An example is not saved in this browser until you make its diagram. It is then saved under its own name, so changing an example does not change the example file itself; open the example again to start from the original.
