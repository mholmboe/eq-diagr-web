DATABASE

Databases

A database consists of two files:

  • A logK-file includes stoichiometry and logK° values for reactions.

  • An elements-file has information on which components should be listed under a given chemical element.

    For example, if the organic ligand glycinate is added to the database, the DATABASE program has no way of knowing that it should be listed under carbon. This information is given in the element-file.

Which databases? Any number of databases may be read together. Three come with the web version and are chosen in the Database menu (see the chemical system). Use Database / Load database files… (or Load… in the file list, or drop the files on the window) for files of your own: you are asked whether to add them to the databases in use or to use them instead. A database read later replaces the reactions of an earlier one that have the same name. In advanced mode, the Database tools tab lists the files, where they can be removed and put in another order.

Sessions (advanced mode). In the Database tools, Save session… downloads all the database files of the list as one file (databases.eqsession), and Open session… puts the files of such a file in the place of those in the list. This is the way to hand a set of databases to somebody else, or to another computer, as the session files of the desktop DataMaintenance name a set of databases.

The binary database supplied consists of two files “Reactions.elb” and “Reactions.db”. These files can not be edited.

What Order? The order in which the databases are searched is shown in the Database tools tab (advanced mode), where the arrows ↑ and ↓ change the order. The order is important because for two species with the same name (but different logK value), only the last one will be retained, see Removing or Changing data.
