Temperature when making an input data file with DATABASE

In DATABASE the logK-files contain equilibrium constants at 25°C, and 1 bar, and temperature extrapolations are possible if data are available, for example ΔH°, etc.

In the Options of the Chemical system tab you can give a temperature other than 25°C, and, in advanced mode, a pressure. The pressure is pSat unless you choose another: the saturation pressure of liquid water (at least 1 bar), which is defined from 0 °C up to the critical point of water, 373.946 °C; above that temperature choose one of the pressures in the list (advanced mode). If temperature data (enthalpies, etc) are missing for any of the species found, the search lists them and no data file is made: change the temperature back to 25°C, or leave those species out.

The KTH course database has equilibrium constants at 25°C only. For other temperatures use the eq-diagr database (or, in advanced mode, the Soltherm database for high temperatures).

If no data is available for temperature extrapolations, you may enter your own data, see:

Temperature when making a diagram in SPANA

DATABASE writes the chosen temperature (and pressure) in the input data-file in a comment at the end of the first line, and this information is used when making a diagram, for example if ionic strength effects are calculated, or if Eh is displayed in diagrams. The diagram tab shows it in the summary of the Chemical system section. In advanced mode, the Temperature field of the diagram's Options gives another temperature for these calculations; the equilibrium constants in the data file are not changed by it.
