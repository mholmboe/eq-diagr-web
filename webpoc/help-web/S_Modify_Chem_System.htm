Changing the chemical system

Open the Chemical system section at the top of a diagram tab. It lists the components and the reactions of the data file; point at a reaction product to see its reaction. Each change is made at once with the programs of the desktop Spana (ModChemSyst and ModReaction), and the tab is marked as changed until the file is saved, which happens when you make the diagram.

  • Untick a reaction, or change its log K
  • Delete a component
  • Exchange a component for a reaction product
  • Merge with another data file (advanced mode)
  • Edit the data file as text (advanced mode)

Unticking reactions, and changing log K

Each reaction has a tick box, as the species found in a database search. Untick a reaction to leave it out of the calculations. The reaction stays in the data file with a "*" before its name (see removing a species with a "*"), and it is listed, unticked and struck through, at the end of the table; tick it to use it again. This is how you leave out a solid that would not form in your experiment, for example a crystalline oxide that precipitates only slowly, see solids.

The log K of each reaction can be edited in its field; the new value is used from the next diagram. A changed value is shown in bold, and the button ↺ beside it takes it back to the value of the file. In live mode each log K also has a slider.

Accumulated and stepwise constants. The log K of a data file is that of the formation of a species from the components: for H3PO4, with the components H+ and PO43−, it is the constant of 3 H+ + PO43− = H3PO4, 21.70, which is the sum of the three steps. An acid is more often described by its steps, pKa 2.15, 7.21 and 12.35. Above the reactions, Constants shown as chooses between the two:

  • accumulated log K: the values of the data file;
  • stepwise pKa: for each species that is a step of an acid, the pKa of that step (pKa = −log Ka), marked “pKa”. Point at the mark to see the reaction, for example H2PO4− ⇌ HPO42− + H+. The hydrolysis of a metal ion is shown in the same way (Fe2+ + H2O ⇌ FeOH+ + H+), and OH− has pKw. Species that are not a step of an acid, for example a metal carbonate complex or a solid, keep their accumulated value, marked “log K”.

In the stepwise view the field, the slider of live mode and the button ↺ work on the step. Changing pKa2 of phosphoric acid, for example, leaves pKa1 and pKa3 as they are: the accumulated values of H2PO4− and H3PO4 in the data file both move by the change. The choice is remembered in the browser; the data file always holds accumulated values.

A changed log K is a trial: it is used for the diagrams of the tab, but it is not written to the file that is saved in the browser when a diagram is made. The saved file keeps its own values, the tab stays marked as changed, and the status line says that the file was saved without the changed log K. To keep the new values, choose File > Save data file in this browser, or answer Save when you close the tab; they are then the values of the file. The downloaded .dat file and a link to the diagram have the values as they are shown. A log K changed in the text of the data file is part of the file and is saved as the rest of it.

In advanced mode, Delete the unticked reactions… removes the reactions that are switched off from the data file for good, after a question. The database is not changed: a new search finds them again.

Components cannot be switched off. A component can, however, be exchanged for a reaction product, and that product then unticked.

Deleting a component

Click delete in the row of a component. The component is removed together with all the reactions in which it takes part: removing Cu2+, for example, also removes CuOH+, CuO(cr) and the other copper species.

Exchanging a component for a reaction product

In the row of a component, choose a reaction product in the list exchange for…. The product becomes a component, and all reactions are rewritten with it. For example:

  • Fe2+ for Fe3+;
  • CO32− for CO2(g), when the equilibrium constants are given with CO32− as the component but the diagram is for a given CO2 pressure (tutorial);
  • a metal ion for a solid, for diagrams of solutions saturated with that solid, or for corrosion (tutorial);
  • H+ for OH−, or a ligand for its protonated form, for titrations (tutorial).

Merging with another data file (advanced mode)

In advanced mode, the button Merge with another data file… (under the reactions) lists the data files saved in this browser; choose one, or A file on this computer…, to add its components and reactions. For example, a file with H+, e− and Fe2+ merged with a file with H+, e− and Cr3+ gives the system H+, e−, Fe2+, Cr3+.

A merged system is probably incomplete: species formed by both Fe and Cr, for example FeCr2O4(s), are in neither file. It is usually better to search the database again with all the components.

Moving components (advanced mode)

The arrows ↑ and ↓ change the order of the components, within the soluble ones and within the solid ones, as in the desktop Spana. The order is that of the data file and of the tables of results.

Editing the data file as text (advanced mode)

For any other change, for example a new reaction, a new component or a comment, click Edit the data file as text… under the reactions, Edit .dat… beside the export buttons above the diagram, or choose File > Edit the data file as text…. The text of the data file is shown with the settings of the form, in the format of the data files. Remember to change the numbers of the first line when you add or remove components, complexes or solids.

Apply (or Ctrl+Enter, ⌘+Enter on a Mac) reads the text as a data file is opened. If the programs cannot read it, their message is shown under the text, the line they stopped at is selected, and nothing is changed. Otherwise the chemical system and the diagram settings are those of the new text, and a text without a diagram gets a default one. The file is written again in the format of the programs: the comments after the reactions are kept, the comment of the first line is not. As after the other changes, the tab is marked as changed and the file is saved when you make the diagram. Cancel and the Escape key ask before they discard changes to the text.

The same can be done outside the app: download the file (.dat), edit it with a text editor, and open it again with File > Open data or plot file….
