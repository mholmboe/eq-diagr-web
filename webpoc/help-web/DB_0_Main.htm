Chemical Equilibrium Diagrams

DATABASE: making a chemical system from a database of equilibrium constants

The Chemical system tab is the web version of the desktop program DATABASE. You choose the chemical components in a periodic table, the program searches the databases for all the reactions between them, and the result is a data file (.dat) for a diagram. The diagram is made in a diagram tab, the web version of SPANA.

Database (equilibrium constants)→Chemical system tab: choose components, search→data file→diagram tab: change the system if needed, make the diagram

Three databases come with the program, and the Database menu switches between them:

  • KTH course database KD1280 (the default): 58 components, log K at 25 °C only, from the course material of the Royal Institute of Technology (KTH), Stockholm.
  • eq-diagr database: the database of the desktop programs, 169 components, with literature references and enthalpy and heat-capacity data for other temperatures. It has the organic ligands (edta, citrate, oxalate and others), which the KTH database has not.
  • Small sample database: nine elements, for trying the program.

In advanced mode the menu also offers the alternative databases of the desktop release (Wateq4F, MintEQ v4, Medusa-Hydra and Soltherm). You can also use databases of your own with Database > Load database files…, see databases.

The database of the desktop programs was first developed at the chemistry departments of the Royal Institute of Technology (KTH), Stockholm, Sweden.
